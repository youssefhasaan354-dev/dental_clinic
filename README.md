# عيادة حياة لطب الأسنان — Hayaah Dental Clinic
### موقع تسويقي فاخر، حديث، متجاوب، يدعم العربية (RTL) والإنجليزية (LTR)

مبني باستخدام: **React 18**, **Vite**, **Framer Motion**, **Sass**, **Bootstrap 5**, **React Icons**, **React Router 6**.

---

## 🌟 نظرة عامة | Overview

تم بناء هذا الموقع كنموذج عرض تقديمي احترافي رفيع المستوى (**Pitch Demo**) ليتم عرضه على صاحب عيادة حياة لطب الأسنان (النزهة ومصر الجديدة، القاهرة).
يتميز الموقع بما يلي:
1. **عربي أولاً (RTL)** كخيار افتراضي مع إمكانية التحويل اللحظي للإنجليزية (LTR) مع مراعاة اتجاه العناصر والقوائم وأيقونات الأسهم.
2. **بيانات موثقة ودقيقة بنسبة 100%**: الهاتف الحقيقي (`02 2635 5669`)، العنوان الدقيق (شارع فريد سميكة، المطار، النزهة، أمام نادي الشمس)، الإحداثيات الجغرافية، رابط خرائط Google الحقيقي، رابط صفحة الفيسبوك، وساعات العمل المعتمدة.
3. **شارة حية لحالة العيادة (مفتوح الآن / مغلق الآن)**: محسوبة تلقائياً بتوقيت القاهرة المحلي (`Africa/Cairo`) مع إبراز يوم الجمعة كعطلة رسمية.
4. **عرض تقييمات Google الحقيقية (4.6 ★ بناءً على 27 تقييماً)** مع زر مباشر لقراءة التقييمات على خرائط Google.
5. **شريط سفلي مثبت للهواتف الذكية (Mobile Sticky Bottom Bar)** يشمل أزرار (اتصال، واتساب، حجز موعد، الاتجاهات).
6. **مقارنة تفاعلية قبل وبعد (Before & After Slider)** تتيح للمريض سحب المقبض لرؤية نتائج العلاج التجميلي والتعويضي.
7. **معرض صور مجهز بمشاهد مكبرة (Accessible Lightbox)** مع دعم مفاتيح الأسهم وزر Esc للإغلاق.
8. **12 خدمة سنية شاملة** لكل منها صفحة تفصيلية كاملة بمراحل العلاج وأعراض الاستشارة والأسئلة الشائعة.
9. **نموذج حجز ذكي وموثق** يتحقق من أرقام الهواتف المصرية ويولد رسالة WhatsApp مجهزة مسبقاً لإرسالها للعيادة بضغطة زر.
10. **جاهز للنشر المباشر على Vercel أو Netlify** بفضل ملفات `vercel.json` و `_redirects`.

## 🚀 التشغيل السريع | Quick Start

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. تشغيل السيرفر المحلي:
```bash
npm run dev
```
سيعمل الموقع على: `http://localhost:3000/`

### 3. بناء النسخة الإنتاجية:
```bash
npm run build
```

### 4. معاينة البناء الإنتاجي:
```bash
npm run preview
```

## 🎨 دليل التعديل السريع (One-File-Per-Concern)

كل ما تحتاجه لتعديل بيانات العيادة، الألوان، الصور، الأطباء، أو الخدمات مجمع في ملفات واضحة ومنظمة:

### 1. تعديل بيانات العيادة، الهاتف، وساعات العمل:
الملف: `src/data/clinic.js`
- لتعديل رقم الهاتف المعروض أو رابط الاتصال: عدّل `phone.raw`, `phone.display`, `phone.international`.
- لتعديل رقم الواتساب المباشر: عدّل `whatsapp.number` (مثال: `2010xxxxxxxx`).
- لتعديل ساعات العمل: عدّل مصفوفة `hours`.
- لتعديل العنوان أو الروابط الجغرافية: عدّل `address`, `coordinates`, `googleMaps`.

### 2. تعديل الألوان والهوية البصرية:
الملف: `src/styles/_variables.scss`
جميع الألوان محددة كـ CSS Variables:
```scss
--color-primary: #583FBC;       // اللون البنفسجي/الأزرق الملكي للعيادة
--color-accent: #2BB3B1;        // اللون التيركواز الطبي المنعش
--color-bg-soft: #DBEFFA;       // لون خلفيات الأقسام المميزة
--color-text: #181945;          // لون العناوين الرئيسي
```

### 3. استبدال الصور بصور حقيقية من العيادة:
الملف: `src/data/images.js`
جميع صور الموقع مربوطة من خلال هذا الملف فقط. لاستبدال أي صورة، ضع الصورة الجديدة في مجلد `src/assets` وغير سطر الاستيراد المقابل في `src/data/images.js` ليتحدث الموقع بالكامل تلقائياً.

### 4. تعديل أو إضافة خدمة جديدة:
الملف: `src/data/services.js`
أضف عنصراً جديداً إلى مصفوفة `SERVICES`:
```javascript
{
  id: "my-service",
  slug: "my-service",
  title: { ar: "اسم الخدمة بالعربية", en: "Service Name in English" },
  shortDesc: { ar: "وصف مختصر", en: "Short description" },
  fullDesc: { ar: "شرح تفصيلي", en: "Full description" },
  duration: { ar: "٤٥ دقيقة", en: "45 mins" },
  whoNeedsIt: { ar: ["العرض الأول", "العرض الثاني"], en: ["Symptom 1", "Symptom 2"] },
  procedureSteps: [ ... ],
  faqs: [ ... ]
}
```

### 5. إضافة أو تعديل المقالات الطبية:
الملف: `src/data/blog.js`
أضف مقالك الجديد إلى مصفوفة `BLOG_POSTS` بالعربية والإنجليزية مع تحديد وقت القراءة والصورة المقابلة.

### 6. إضافة أسماء وصور الأطباء الحقيقيين:
الملف: `src/data/team.js`
تم وضع مسميات تخصصية محايدة تجنباً لاختلاق أسماء وهمية. عندما يزودك الطبيب بالأسماء الحقيقية، استبدل فقط `placeholderNameAr` و `image`.

### 7. تفعيل سلايدر آراء المرضى:
الملف: `src/data/testimonials.js`
المصفوفة حالياً فارغة عمداً احتراماً للشفافية الطبية وتكتفي بعرض تقييم خرائط Google المعتمد (4.6★ من 27 تقييماً). بمجرد إضافة نصوص تقييمات حقيقية للمصفوفة، سيعمل سلايدر آراء المرضى تلقائياً.

## 🚢 النشر على Vercel | Vercel Deployment

المشروع مجهز كلياً للنشر السلس على منصة **Vercel**:
1. ارفع الكود إلى مستودع GitHub.
2. ادخل إلى [vercel.com](https://vercel.com) واختر **New Project**.
3. استورد مستودع GitHub وسيتم اكتشاف المشروع تلقائياً كـ **Vite**:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. اضغط **Deploy**. تم تضمين ملف `vercel.json` لضمان عمل توجيه مسارات الـ SPA بنجاح (Single Page Application Fallback).
